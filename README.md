## 四、個人回答

### 💡 問題一：
**測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？**

* **桌遊費用應以 3 人計算之原因：**
  原始桌遊名單清理後（去空白、轉小寫）產生的串列為 `['amy', 'ben', 'amy', 'cora']`。其中 `'amy'` 出現了兩次。根據活動規則「同一個人在同一場活動中重複出現，只算一位參加者，也只收一次費用」，因此經過 `set` 去重後的名單為 `['amy', 'ben', 'cora']`，實際應付費人數為 3 人。

* **拆成 List 的保留與失去：**
  * **保留了：** 原始資料的**先後順序**與**重複報名**記錄。
  * **失去了：** 無法自動判別重複，直接拿 `list` 長度計費會導致對重複報名者重複收費。

* **轉成 Set 的保留與失去：**
  * **保留了：** **唯一且不重複**的元素特徵，可以直接得出精確的不重複計費人數。
  * **失去了：** 資料原本的**先後順序**（Set 是無序的），以及重複出現的**次數資訊**。

### 💡 問題二：
**測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。**

* **集合關係說明：**
  設桌遊去重後的集合為 $A$，電影去重後的集合為 $B$：
  * 桌遊去重集合 $A = \{\text{"amy", "ben", "cora"}\}$，人數 $|A| = 3$
  * 電影去重集合 $B = \{\text{"amy", "ben", "cora"}\}$，人數 $|B| = 3$
  * 共同參加者（交集）$A \cap B = \{\text{"amy", "ben", "cora"}\}$，人數 $|A \cap B| = 3$
  * 總不重複人數（聯集）$A \cup B = \{\text{"amy", "ben", "cora"}\}$，人數 $|A \cup B| = 3$

* **算式與人次、金額說明：**
  * **報名人次**定義為「兩場去重後的人數相加（重複參加兩場的人算兩次）」：
    $$\text{報名人次} = |A| + |B| = 3 + 3 = 6 \text{ 人次}$$
  * **總應付金額**為兩場活動各自去重後人數乘以單價之和。因為規則中「同一個人可以參加兩場，兩場費用分別計算」，因此 3 位參加者每人都必須繳交兩場活動的費用：
    $$\text{桌遊費用} = 3 \times 120 = 360 \text{ 元}$$
    $$\text{電影費用} = 3 \times 80 = 240 \text{ 元}$$
    $$\text{總應收金額} = 360 + 240 = 600 \text{ 元}$$
    這解釋了為什麼雖然聯集不重複人數只有 3 人，但因為兩邊皆各自成立收費，所以總人次為 6 人次，總費用依然為 600 元。
